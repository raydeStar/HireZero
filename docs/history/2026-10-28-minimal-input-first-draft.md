# Minimal-input first draft and first-goal naming

The owner wants a business sentence and a goal to produce useful work without coaching. Earlier evaluation
briefs often supplied detailed scope, exclusions, contact routes and quality constraints. This cycle tested
one fresh fictional two-person presentation studio using only a business sentence and a landing-page goal.
It used the installed baseline prompts; no prompt candidate was introduced.

## Raw Home result

Home selected Marketing and completed one native Luna request through Codex OAuth. The visible single-run
consent disclosed high effort, a 3,000-output-token target, a 90-second local deadline and one intended
existing credit, all soft limits. The primary CTA saved context, prepared and dispatched the job, then
opened the result without a second authorization screen. No website was provided or researched.

The first raw output contained a complete short landing-page draft, audience/purpose/material prompts to
help a prospective customer describe their presentation, and an explicit enquiry-route placeholder.
It did not invent prices, packages, turnaround times, guarantees or a contact channel. Review notes cited
the supplied brief and identified the missing route.

Assistant assessment: a usable starting draft once the route is supplied, but not distinctive marketing.
The headline is generic and the body repeats the business sentence. Sparse input does not by itself
explain the earlier failures, and this one result cannot establish repeatable usefulness. Owner acceptance
remains unproven. The original output remains version 1 with model provenance; no editorial copy was made.

Reported usage: 5,770 input tokens, 343 output tokens, zero reasoning tokens. High effort was requested;
the receipt does not demonstrate that reasoning tokens were used. Actual credit charges were not returned.
The Luna grant now has 21 completed requests and 10 remaining, with 140,927 reported input/output tokens.
The separate two-call Sol grant remains exhausted. No model default, publishing or recurrence changed.

## Discovered UX fix

The first Home result was labeled with the employee's default “Private conversation” title, while later
goals already used the owner's goal. New first-goal conversations now use that same goal title. The initial
conversation is reused rather than leaving an extra empty conversation. Existing titles and saved results
are preserved; the change applies to newly prepared first goals.

Verification: all nine focused goal-start tests pass, including exact request recovery and separate later
goal titles. Release build and formatting pass. Both local installs received the fix with application/data
backups, installed-file checks and preserved accounts, work, schedules and audit chains. A separate fictional
installed request confirmed the saved title and was canceled before any model execution. All 21 raw Luna
outputs and the earlier acceptance drafts were rechecked unchanged. Private receipts and outputs remain
outside source control.
