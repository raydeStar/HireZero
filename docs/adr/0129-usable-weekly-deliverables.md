# 0129 - Usable weekly deliverables and direct revision review

Status: accepted, 2026-10-27.

A real first-plan review found that structured output can still leave the useful work undone: posts described
the product, promised a demonstration without including it, and asked broad questions. The first-assignment
default also requested several experiments and only one sample, diluting the role's focused recommendation.

Marketing starter plans now request one focused week, three distinct finished drafts and the actual useful
template, checklist or worked example referenced by the copy. Proposed audiences and fictional examples remain
labeled. Missing distribution is noted once; it does not justify inventing accounts, offers, customer results
or fulfillment commitments. On revision, instructions target the missing substance rather than merely headings.
These instructions live in the Marketing role and its UI setup; core remains role-neutral.

Reports open in full, retaining optional collapse. Copy and Markdown download use the exact stored body,
including any exact-call text. Neither action changes approval, provenance or stored content. Clipboard failure
offers download or manual selection. Existing raw-HTML and image restrictions remain in place.

Creating a revision opens the resulting task directly. Opening it later from the original result also retains
focused work mode rather than dropping the owner into chat. An already focused result does not offer a redundant
"Read result" action. Feedback persistence and separate execution authorization are unchanged.

Revision feedback remains expanded before execution and collapses once a result exists, so a long request does
not hide the new draft. The prior draft and exact feedback remain available in that disclosure.

The edited private weekly plan is an editorial deliverable, not evidence that a model followed the new prompt.
Fictional E2E checks establish mechanics only. No additional live model request is authorized or made by this
change; improved native generation and owner usefulness acceptance remain separate observations.
