# 0137 - Complete assets in the first Marketing assignment

Status: accepted, 2026-10-27.

A revised plan can benefit from an editorial starting copy and several corrections. That does not establish
the quality of the default first assignment. A fresh native check of the existing default produced a worksheet,
but its example mostly listed ideas for assets, the drafts repeated a broad closing question, and the preparation
schedule did not clearly cover all three posts.

Marketing's role instructions now require a completed example with a blank worksheet, actual versions in a
before/after, a distinct action for each post and an observable numeric learning target. Preparation covers each
post with review actions and estimates; the owner is not assigned creation of the central assets. The example's
audience remains distinct from the campaign audience. Repeated uncertainty statements do not pad open decisions.

New first-assignment suggestions explicitly request two brief-grounded observations, explain their connection to
the experiment, and supply three Monday/Wednesday/Friday posts of 40–80 words each. The suggested preparation
budget is at most 90 minutes and the entire result stays under 500 words. The owner can edit that request before
preparation. Existing task inputs, outputs and approved context are not rewritten.

The first-run check uses a fresh private conversation and the actual role-owned suggested request. It includes
the approved brief and no previous draft, revision context or selected output. The native call remains separately
authorized and measured. This changes no model route, effort, runtime pin, token policy, automatic execution or
publishing authority. Existing schedule approvals must still match current instructions before execution.

One improved fresh result is evidence of capability on this case, not a quality guarantee or customer acceptance.
