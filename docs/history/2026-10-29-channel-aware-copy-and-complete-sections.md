## Copy bug found during the walkthrough

A standalone bold sentence inside a post was mistaken for a new section title. Copying the post
therefore returned only its introduction: 141 characters instead of the complete 589-character
section. This was observed with an actual clipboard read, not inferred from the screen.

Real Markdown headings now include child headings and bold content until the next peer or parent
heading. Bold-title fallback is enabled only when that style begins a section, so later emphasis
inside prose is not promoted to a heading. Copies remain exact source slices, and whole-draft
copy/download remain available. No artifact content is changed by this presentation fix.

The installed button now copies all 589 characters, matching the saved section exactly, including
its bold hook, checklist and closing question. There is no spurious copy button on the emphasized
sentence. The new regression test failed before the fix and passes after it; it also covers nested
headings, bold-title fallback, CRLF, separators, and headings inside quotes and code fences.
