# ADR 0164: Generate a first draft with one Home consent

Status: accepted; supersedes the separate dispatch step in ADR 0163.

The owner requested optional website context and generation directly from Home. Requiring a second job-card
authorization made the primary action misleading and delayed the first useful result.

Home now loads the actual model, provider, runtime and policy before consent. The owner authorizes the supplied
details, optional bounded website discovery and one private model request together. Durable browser checkpoints
sequence owner-fact setup, optional discovery, assignment preparation and exact-digest dispatch. Prepared terms
must match the displayed terms and allowance. Changed terms stop the sequence for a fresh review. Uncertain
operations are reconciled through existing receipts; neither website reads nor model requests are replayed.

The website is explicitly selected by the owner. Its discovery reuses existing read limits and immutable evidence
storage. Up to three 1,500-character excerpts enter a separate unverified reference field, with source addresses,
dates, clipping and availability notices. They do not become approved company facts. Existing owner facts take
precedence. The reference follows native revisions and is fenced when its business identity changes. Unavailable
pages permit a draft from the supplied facts, with the limitation retained in its context.

This authorization covers the specific first draft only. It grants no publishing, recurring execution, provider
fallback or automatic repair. Acceptance evaluates the first raw result without an assistant-authored replacement.
