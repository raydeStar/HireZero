# ADR 0161: Recommend the requested work before incidental topics

Status: accepted

## Context

Role suggestions used fixed role-specific priorities. A content-plan goal that also mentioned a website and a
workflow ranked CEO and Developer above Marketing. This rewarded incidental vocabulary instead of the owner's
requested result.

For existing employees, the conversation shortcut can open an old chat rather than the latest useful work.

## Decision

Role modules keep their own matching vocabulary and setup templates. They use a common specificity scale:
requested work, named deliverable, topic, then a general starting option. Show at most three matches from the
strongest available level. Equally specific matches follow their order in the goal, with the role name as a stable
tie-breaker. Explicit exclusions such as "do not" or "avoid" in the same clause do not contribute a match.

Only the current approved, owner-provided or sourced goal remains eligible. A reason quotes the matching goal
text. Existing-employee reuse, editable setup, first-assignment review and the all-roles catalog stay available.
There is no model call, automatic hire or permission change.

For existing employees, offer a separate latest-result shortcut beside the conversation link. It opens the exact
task and thread in Work review, choosing the most recently updated task with a saved artifact that is awaiting
review or completed. A later request without a result, canceled work or superseded work does not displace it.
The conversation link keeps its existing behavior. Neither navigation action changes artifact approval.

## Consequences

Writing website copy can lead to Marketing while repairing website accessibility leads to Developer. Coordinating
those tasks can lead to CEO. The company shell remains role-neutral. These bounded English-language heuristics
are explainable suggestions, not general intent understanding; ambiguous or unsupported phrasing can still need
the owner's choice. Real customer relevance remains a separate validation gate.
