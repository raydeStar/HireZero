# Morning work: direct corrections and readable vetoed drafts

The daily-use pass keeps the installed chat polish and focuses on Home's morning proposals.

## Changes

- A failed schedule lookup now shows **Retry morning work**, instead of looking like no shift exists and offering
  another one. Retry only reads saved state. One loader owns the morning card and its retry; the optional shift
  offer appears there once the approved goal ladder is ready.
- **That's inaccurate** sits beside each proposal. It opens a focused correction field in the same card and binds
  the saved direction to that proposal's title, rather than the report's opening heading. Saved decisions remain
  available in the collapsed history. The existing draft-level correction stays available in conversations.
- A veto still blocks an unstarted proposal, but it no longer hides **Read the draft** or an existing task's link.
  Undo removes the direction without starting work. Raw model artifacts remain unchanged.

  next round, unchanged raw output, and undo without another model request. Existing preparation/dispatch/lesson

limitation.
