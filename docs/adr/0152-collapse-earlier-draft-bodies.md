# 0152 - Keep earlier draft bodies collapsed during review

Status: accepted, 2026-10-28.

After several revisions, the review screen expanded every saved draft. The accepted result was first, but
its entire history still filled the page and pushed task controls below repeated deliverables.

Each draft now has a native disclosure with its existing draft number, authorship and review state.
The first result opens by default; earlier bodies and their controls stay collapsed until requested.
The display order from ADR 0141 is unchanged: newest first for open work, approved first for completed work.
Keyboard and pointer users can reopen any copy for comparison without changing its body or review state.

This is presentation only. It creates no work, model request, approval or stored-data change.
